# Lessons

- When the user narrows the workspace scope, stop sibling-repository work and
  keep subsequent fixes, issues, and releases within the named repository.
- Distinguish a shipped warning fix from an unimplemented progress feature;
  verify each requested behavior independently before describing release status.
- When asked to close an unreproduced historical report, record the evidence
  and close it as unreproduced rather than leaving it open indefinitely or
  implying that an unverified fix shipped.
